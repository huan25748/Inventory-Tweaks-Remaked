Inventory Tweaks Remaked

物品栏整理、容器排序、自动装填与物品树 —— 1.12.2 Inventory Tweaks 的现代移植版使用文档。

把对应游戏版本的 jar 放进 mods 文件夹即可。它是纯客户端模组，服务器不需要安装，也不会向服务器发送额外数据包。

提示 第一次启动会在 config/InvTweaks/ 下生成默认配置。生成过程不会在聊天栏提示，只在 logs/latest.log 里留一行记录。

快速开始

装好模组后进游戏，打开背包就能看到标题栏右上角多出一个 “…” 按钮——它在，说明模组已经正常加载。点它可以进入设置界面。

  • R：整理鼠标所指的区域。不用先打开背包，游戏中直接按也有效。
  • 鼠标中键：整理；对箱子连续点击会在三种算法之间循环。
  • 容器标题行右侧的按钮：默认排序、竖排、横排、设置与物品转移。
  • Ctrl / Shift / 空格 / Alt + 左键：移动或丢弃物品。

整理规则、方案与物品分类都保存在 config/InvTweaks/，改完不需要重启游戏，保存后直接整理即可生效。

安装与版本

同一个模组按加载器与游戏版本分别打包，请只安装与实例完全对应的那个文件。

加载器游戏版本jar 文件名
Fabric1.20.1inventorytweaksremaked-fabric-1.20.1-1.0.0.jar
Fabric1.21 / 1.21.1 / 1.21.3 / 1.21.4 / 1.21.5 / 1.21.8 / 1.21.10 / 1.21.11inventorytweaksremaked-fabric-<版本>-1.0.0.jar
Fabric26.1.2 / 26.2 / 26.3inventorytweaksremaked-fabric-<版本>-1.0.0.jar
Forge 47.x1.20.1inventorytweaksremaked-forge-1.20.1-1.1.0.jar
NeoForge 21.x1.21 / 1.21.1 / 1.21.3 / 1.21.4 / 1.21.5 / 1.21.8 / 1.21.10 / 1.21.11inventorytweaksremaked-neoforge-<版本>-1.1.1.jar
NeoForge 26.x26.1.2 / 26.2 / 26.3（需要 Java 25）inventorytweaksremaked-neoforge-<版本>-1.1.0.jar

Fabric 版本需要对应版本的 Fabric Loader 与 Fabric API；Forge / NeoForge 版本不需要额外前置。

基础整理

R 键整理：跟着鼠标走

按 R 时，整理哪个区域取决于鼠标指针停在哪。你不需要先打开背包，在游戏里直接按也有效：

鼠标指向结果
箱子（容器）里的格子只整理容器
背包 / 快捷栏只整理背包
合成格、按钮、GUI 空白处容器与背包一起整理（没有容器时就是整理背包）

鼠标中键

中键整理同样按鼠标位置判断区域。对箱子连续点击中键会在 默认 → 竖排 → 横排 三种算法之间循环。

中键还有一个特殊情况：当鼠标指向合成输入格时，它不会整理，而是把格子里的物品数量平均分配，方便你摆配方。例如做木棍时会保证上下两格的木板数量一致。

整理算法

算法放置顺序适用场景
默认按物品树中的分类顺序逐项填充日常背包、箱子
竖排（按列）一列一列从上往下填想按列归类物品
横排（按行）一行一行从左往右填想按行归类物品

创造模式背包

创造模式的物品选择面板只保留一个设置按钮，位置在面板标题行右端；R 与中键不会整理创造面板里的物品列表。

容器上的按钮

下面的图标按模组实际的像素绘制还原（10×10 的按钮放大到 30×30），游戏里看到的就是这个样子。鼠标停留约 0.8 秒会弹出提示框，内容即表中的「悬停提示」。

图标位置悬停提示作用
排序行最左默认排序方式用当前配置的默认算法整理容器
排序行中间按列整理竖排：一列一列地放物品
排序行中间按行整理横排：一行一行地放物品
排序行最右物品栏设置打开 Inventory Tweaks 设置界面
「物品栏」行右端，靠左转移物品至容器单击：只补容器里已有的同类物品；Shift：除快捷栏外全部；Alt+Shift：全部
「物品栏」行右端，靠右转移物品至物品栏Shift：把容器里的物品全部取回背包
提示 竖排 / 横排按钮只在容器宽度不超过 9 格时出现。遇到精妙背包、精妙存储这类自带按钮的界面，整排按钮会自动左移避让，不会重叠。

快捷键

默认键位如下，均可通过背包里的 “…” 菜单修改，或直接编辑 config/InvTweaks/InvTweaks.cfg。

操作默认键说明
整理鼠标所指区域R不必打开背包，游戏中任意时刻可用
整理（循环算法）鼠标中键对箱子循环切换默认 / 竖排 / 横排
移动 1 个物品Ctrl + 左键把一格里的 1 个物品移到目标格
移动所有同类型物品Ctrl + Shift + 左键同一种物品的全部堆叠一起移动
移动一叠物品Shift + 左键把整组物品一次性移动
移动所有物品空格 + 左键把区域内所有物品（不限类型）移走
移动到上方区域↑ + 左键移到容器 / 背包的上半部分
移动到下方区域↓ + 左键移到下半部分
丢弃Alt + 左键把物品丢到地上
移动到指定快捷栏格1~9 + 左键直接放进对应快捷栏格
切换整理方案R + 1~9编号对应规则文件里方案出现的顺序
循环切换整理方案按住 R 约 1 秒按顺序轮换方案
注意 「切换整理方案」只有在规则文件里定义了两套以上方案时才有反应；默认只有一套默认规则。

自动装填

吃东西、工具损坏、方块用完导致手中物品减少时，模组会自动从背包里找同类物品补到当前格。

配置项默认说明
enableAutoRefilltrue自动装填总开关
autoRefillBeforeBreakfalse工具彻底损坏之前就提前更换
autoRefillDamageThreshhold5剩余耐久低于该值时触发交换

哪些物品允许自动补货由规则文件里的 autorefill 行决定；被 FROZEN 锁定的格子不会参与自动装填。

配置文件

全部位于 config/InvTweaks/：

文件作用
InvTweaks.cfg开关与按键（properties 格式）
InvTweaksRules.txt排序规则与多套方案
InvTweaksTree.txt物品分类树（内容是 XML）
trees/*.tree附加物品树片段，启动时与主树合并
InvTweaksCompatibility.xml可选，为其它模组的容器声明兼容信息
提示 规则文件可以在游戏内通过 “…” → 「打开排序规则文件…」直接打开，保存后无需重启，切回游戏再整理一次即可。

排序规则（InvTweaksRules.txt）

每行是一条约束，格式固定为两段：

<目标> <关键字>

目标是背包里的位置（单格、整行、整列或矩形），关键字来自物品树里的类别名或物品名。例如写 D5 pickaxe，整理时背包最下面一行（快捷栏）第 5 格会放上当前最好的镐子。

规则文件默认就会带一条 D LOCKED，表示快捷栏不会被自动整理塞入物品。

区域写法

背包按 9 列 4 行编号：列 1~9（从左到右），行 a~d（从上到下，d 是快捷栏）。

写法含义
D1单格：第 D 行第 1 列
D整行，从左往右填
1整列，默认从下往上填
A5-C9矩形：从 A5 到 C9
A1-C3矩形，另一种方向（四个角写法顺序不同，填充方向也不同）
提示 矩形的四个角可以写成 A1-C3、C3-A1、A3-C1、C1-A3，它们不是完全等价的——起始角决定从哪个角落开始填。挑一个符合你习惯的写法即可。

修饰符

写在目标末尾，可以叠加：

修饰符含义
r反向：从右往左、或从上往下填充
v竖排优先：先上下、再左右（主要用于矩形）

例如 Ar 是第 1 行反向填充，A1-C5v 是矩形内竖排优先。

关键字

所有物品名与大量类别名都可以直接用，例如 pickaxe、edibleFood、blocks、equipment。完整列表就是物品树文件的内容。

关键字不区分大小写和空格：woodenSword、WOODSWORD、Wooden Sword 等价。

锁定与冻结

写法效果
<目标> LOCKED整理时不会把别的物品塞进这些格子；但更具体的目标可以覆盖它（D LOCKED 会被 D1 torch 覆盖）
<目标> FROZEN格子里的物品完全不动，整理与自动装填都不会碰
autorefill <关键字>只对匹配关键字的物品自动补货（不写则全部）

多套方案

用「单个单词 + 冒号」单独成行来开始一个方案，后面的规则都属于它：

Mining:
D1 pickaxe
D2 torch

Fighting:
D1 sword
D5 edibleFood

切换方式：按住 R 约 1 秒循环，或者 1~9 + R 直接跳到对应序号的方案（第一套是 1）。

原作者自己使用的规则：

完整示例

# 井号开头是注释
[Default]
# 第 1 列放武器
1 weapon
# 第 1 行放方块
a block
# 单格放食物
a1 food
# 右下角两格锁住

注意 两种写法都支持：Default:（官方风格）与 [Default]（配置文件里的分段写法）。同一个文件里保持一致即可。

物品树（InvTweaksTree.txt）

物品树定义「规则里能用的关键字」，以及同一类别内物品的先后顺序。顺序很重要：写 D1 sword 时，排在前面的剑会优先被选中。

基本结构与自定义类别

文件内容是 XML，根元素固定为 stuff。自定义类别直接嵌套在里面，元素名就是新的关键字：

<stuff treeVersion="1.20.1">
  <myCategory>
    <dirt id="minecraft:dirt"/>
    <cake id="minecraft:cake"/>
  </myCategory>
</stuff>

这样规则里写 myCategory 就只会匹配泥土和蛋糕。物品不需要从原类别里删掉，同一个物品可以出现在多个类别里；新类别建议放在 <stuff> 下面靠前的位置。

ID 与变种

有些物品需要配合变种值（damage）才能区分：

<sexyWools>
  <magentaWool id="minecraft:wool" damage="2"/>
  <pinkWool id="minecraft:wool" damage="6"/>
  <purpleWool id="minecraft:wool" damage="10"/>
</sexyWools>

特殊数据

药水、命名物品这类需要额外数据才能唯一确定：

<specialPotion>
  <specialPotionA id="minecraft:potion" data='{Potion:"minecraft:strong_healing"}'/>
</specialPotion>

<specialPickaxe id="minecraft:diamond_pickaxe"
  data='{display:{Name:"My Special Pickaxe"}}'/>

属性

属性用于说明
id物品注册名，如 minecraft:stone
damage物品变种值，默认通配
dmin / dmax类别按 damage 范围批量生成条目
class类别按类名匹配：armor、sword、bow、pickaxe、shovel、axe、hoe、shears、arrow、fishing
data类别附加条件，如 data="toolclass:pickaxe"、data="armortype:head"、data="isshield:true"；多个用逗号分隔
order任意同级内的先后顺序
mergePrevious / mergeChildren任意与上一项 / 子项合并顺序，用于让某些物品排在一起
treeVersion根元素树对应的游戏版本号，仅作记录；版本变化时会备份旧文件并重建

扩展与合并

把额外片段放进 config/InvTweaks/trees/，文件名以 .tree 结尾，启动时自动与主树合并；改坏了直接删掉会自动重建，旧文件会备份为 *.bak。

注意 物品树里关键字拼错时，规则文件里对应的那一行会被当作无效关键字跳过，游戏内会在聊天栏提示无效关键字。

容器兼容性（InvTweaksCompatibility.xml）

默认不存在，需要时自己创建。它告诉模组哪些容器应该显示按钮、哪些只显示设置按钮：

<root>
  <!-- 当箱子处理：显示排序按钮 -->
  <chest class="mod.container.MyChestContainer" row_size="9" large_chest="false"/>
  <!-- 当普通容器处理：只显示设置按钮 -->
  <inventory class="mod.container.MyInventoryContainer" disable_buttons="false"/>
</root>

它只能表达最基础的兼容信息，并不保证对所有模组都有效；容器行为异常时优先联系模组作者提供 API 支持。

常见问题

聊天栏提示「Mod 无法工作，因为找不到…」

jar 里的默认配置资源缺失（通常是打包问题）。删掉 config/InvTweaks/ 重启，正常版本会自动重建。

按 R 没反应

确认三件事：按的是排序键（默认 R，可在「控制 → 按键」里查）；当前界面允许整理；鼠标停在格子上（决定整理哪个区域）。

修饰键 + 左键没反应

检查 InvTweaks.cfg 里 enableShortcuts=true，并确认设置里的「快捷键」是开启状态；另外按键不能和游戏原有按键冲突。

R + 数字 / 按住 R 切换方案没反应

规则文件里只有一套方案时没有可切换的目标。至少再写一段 Mining: 之类的方案才会生效。

改完配置不生效

规则与按键保存后切回游戏再整理一次即可；物品树改动建议重启客户端。版本升级后如果树被重建，可在 config/InvTweaks/ 里找到 *.bak 备份。

模组物品没法按我想的方式排序

编辑 InvTweaksTree.txt，把物品按 id 加进你想要的类别。不确定 id 时，在游戏里按 F3 + H 打开高级提示框，再把鼠标移到物品上查看。

图标在我的材质包里很难看

默认用原版按钮贴图绘制。可以在材质包里放一张 assets/inventorytweaks/textures/gui/button10px.png 覆盖它。
