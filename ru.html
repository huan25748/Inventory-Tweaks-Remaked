Inventory Tweaks Remaked

Сортировка инвентаря, сортировка контейнеров, автопополнение и дерево предметов — современный порт Inventory Tweaks для Minecraft 1.12.2.

Поместите jar для своей версии игры в папку mods. Это клиентский мод: серверу он не нужен, лишние пакеты не отправляются.

СОВЕТ При первом запуске в config/InvTweaks/ создаётся конфигурация по умолчанию. В чате ничего не появляется — только одна строка в logs/latest.log.

Быстрый старт

После установки откройте инвентарь: в правом верхнем углу заголовка появится кнопка «…». Если она есть, мод загрузился. Нажмите её, чтобы открыть настройки.

  • R — сортирует область под курсором. Инвентарь открывать не обязательно.
  • Средняя кнопка мыши — сортировка; в сундуке каждое нажатие переключает три алгоритма.
  • Кнопки справа в строке заголовка контейнера: обычная сортировка, вертикальная, горизонтальная, настройки и перенос предметов.
  • Ctrl / Shift / Пробел / Alt + ЛКМ — перенос или выбрасывание предметов.

Правила, профили и категории хранятся в config/InvTweaks/. Перезапуск не нужен: сохраните файл, вернитесь в игру и отсортируйте ещё раз.

Установка

Для каждого загрузчика и версии игры собирается отдельный jar. Устанавливайте только файл, точно соответствующий вашему профилю.

ЗагрузчикВерсия игрыИмя jar
Fabric1.20.1inventorytweaksremaked-fabric-1.20.1-1.0.0.jar
Fabric1.21 / 1.21.1 / 1.21.3 / 1.21.4 / 1.21.5 / 1.21.8 / 1.21.10 / 1.21.11inventorytweaksremaked-fabric-<версия>-1.0.0.jar
Fabric26.1.2 / 26.2 / 26.3inventorytweaksremaked-fabric-<версия>-1.0.0.jar
Forge 47.x1.20.1inventorytweaksremaked-forge-1.20.1-1.1.0.jar
NeoForge 21.x1.21 / 1.21.1 / 1.21.3 / 1.21.4 / 1.21.5 / 1.21.8 / 1.21.10 / 1.21.11inventorytweaksremaked-neoforge-<версия>-1.1.1.jar
NeoForge 26.x26.1.2 / 26.2 / 26.3 (нужна Java 25)inventorytweaksremaked-neoforge-<версия>-1.1.0.jar

Для Fabric нужны соответствующие Fabric Loader и Fabric API; версии Forge и NeoForge дополнительных зависимостей не требуют.

Основы сортировки

Клавиша R следует за курсором

Область сортировки зависит от положения курсора. Инвентарь открывать не нужно:

Курсор надРезультат
Ячейками сундука (контейнера)Сортируется только контейнер
Инвентарём / хотбаромСортируется только инвентарь
Сеткой крафта, кнопками, пустым местомКонтейнер и инвентарь сортируются вместе (только инвентарь, если контейнера нет)

Средняя кнопка мыши

Средняя кнопка тоже определяет область по курсору. В сундуке нажатия переключают обычный → вертикальный → горизонтальный.

Особый случай: если курсор над ячейкой крафта, сортировки нет — вместо неё стак делится поровну, например чтобы распределить древесину между двумя ячейками при крафте палок.

Алгоритмы сортировки

АлгоритмПорядок заполненияКогда удобен
ОбычныйПредмет за предметом по порядку дереваПовседневный инвентарь и сундуки
Вертикальный (по столбцам)Столбец за столбцом, сверху внизГруппировка по столбцам
Горизонтальный (по строкам)Строка за строкой, слева направоГруппировка по строкам

Творческий инвентарь

В творческом режиме остаётся только кнопка настроек в правом конце строки заголовка; R и средняя кнопка никогда не сортируют творческий список.

Кнопки контейнеров

Иконки ниже повторяют реальную пиксельную графику 10×10 (увеличена до 30×30). При наведении примерно через 0,8 с появляется подсказка из таблицы.

ИконкаПоложениеПодсказкаДействие
Крайний слева в рядуОбычная сортировкаСортирует контейнер текущим алгоритмом
Середина рядаПо столбцамВертикально: по одному столбцу
Середина рядаПо строкамГоризонтально: по одной строке
Крайний справа в рядуНастройки инвентаряОткрывает настройки Inventory Tweaks
Конец строки инвентаря, левееПеренести в контейнерКлик: дополняет существующие стаки; Shift: всё, кроме хотбара; Alt+Shift: всё
Конец строки инвентаря, правееПеренести в инвентарьShift: забирает всё из контейнера
СОВЕТ Кнопки «вертикально/горизонтально» появляются только при ширине контейнера до 9 ячеек. Если контейнер рисует свои кнопки (Sophisticated Backpacks и подобные), ряд сдвигается влево, чтобы не перекрываться.

Клавиши по умолчанию перечислены ниже. Их можно изменить через меню «…» в инвентаре или в config/InvTweaks/InvTweaks.cfg.

Автопополнение

Когда вы съедаете предмет, ломаете инструмент или заканчиваете стак блоков, мод автоматически переносит подходящий предмет из инвентаря в текущую ячейку.

ПараметрПо умолчаниюОписание
enableAutoRefilltrueОбщий выключатель
autoRefillBeforeBreakfalseМенять инструмент до полной поломки
autoRefillDamageThreshhold5Менять при остатке прочности ниже этого значения

Какие предметы пополняются, задаёт строка autorefill в файле правил; ячейки FROZEN в автопополнении не участвуют.

Файлы конфигурации

Всё находится в config/InvTweaks/:

ФайлНазначение
InvTweaks.cfgПереключатели и клавиши (формат properties)
InvTweaksRules.txtПравила сортировки и профили
InvTweaksTree.txtДерево категорий (содержимое XML)
trees/*.treeДополнительные фрагменты, объединяемые при запуске
InvTweaksCompatibility.xmlНеобязательно: совместимость контейнеров
СОВЕТ Файл правил можно открыть из игры: «…» → «Открыть файл правил сортировки…». Сохраните и отсортируйте ещё раз.

Правила сортировки (InvTweaksRules.txt)

Каждая строка — одно условие из двух полей:

<область> <ключевое слово>

Область — позиция в инвентаре (ячейка, строка, столбец или прямоугольник); ключевое слово берётся из дерева предметов. Например, D5 pickaxe кладёт лучшую кирку в 5-ю ячейку нижней строки (хотбара).

В файле по умолчанию уже есть D LOCKED: хотбар не заполняется автоматической сортировкой.

Области

Инвентарь нумеруется: 9 столбцов и 4 строки. Столбцы 1–9 слева направо, строки a–d сверху вниз (d — хотбар).

СинтаксисЗначение
D1Одна ячейка: строка D, столбец 1
DВся строка, слева направо
1Весь столбец, по умолчанию снизу вверх
A5-C9Прямоугольник от A5 до C9
A1-C3Прямоугольник, другой порядок углов (другое направление заполнения)
СОВЕТ Прямоугольник записывается как A1-C3, C3-A1, A3-C1 или C1-A3. Это не одно и то же: первый угол задаёт точку начала заполнения.

Модификаторы

Добавляются в конец области и могут сочетаться:

МодификаторЗначение
rОбратный порядок: справа налево или сверху вниз
vСначала вертикально: сверху вниз, затем влево-вправо (для прямоугольников)

Например, Ar заполняет строку 1 в обратном порядке, а A1-C5v — прямоугольник сначала по вертикали.

Ключевые слова

Имена предметов и многие категории используются напрямую: pickaxe, edibleFood, blocks, equipment и другие. Полный список — содержимое файла дерева.

Регистр и пробелы не важны: woodenSword, WOODSWORD и Wooden Sword равнозначны.

Блокировка и заморозка

СинтаксисЭффект
<область> LOCKEDДругие предметы туда не попадут; более точная область отменяет это (D LOCKED перекрывается D1 torch)
<область> FROZENПредметы в этих ячейках не двигаются ни при сортировке, ни при автопополнении
autorefill <ключевое слово>Пополнять только подходящие предметы (если не указано — все)

Несколько профилей

Профиль начинается со слова и двоеточия в отдельной строке; следующие правила относятся к нему:

Mining:
D1 pickaxe
D2 torch

Fighting:
D1 sword
D5 edibleFood

Держите R около секунды для перебора или нажмите 1–9 + R, чтобы перейти к профилю по номеру (первый — 1).

Официальный пример

Правила, которыми пользуется автор оригинала:

Default:

D1 pickaxe
D2 axe
D3 shovel
D4 sword
D5 edibleFood
D9 torch

A1-C5v stuff
A9-C6v blocks

Полный пример

# строки, начинающиеся с #, — комментарии
[Default]
# оружие в столбец 1
1 weapon
# блоки в строку 1
a block
# еда в одну ячейку
a1 food
# заблокировать две ячейки справа снизу
b8-c9 locked
# пополнять только инструменты
autorefill tool
ВНИМАНИЕ Поддерживаются оба стиля: Default: (документация) и [Default] (секции). В одном файле придерживайтесь одного.

Дерево предметов (InvTweaksTree.txt)

Дерево задаёт ключевые слова для правил и порядок предметов внутри категории. Порядок важен: при D1 sword предпочтение отдаётся мечам, указанным выше.

Структура и свои категории

Файл в формате XML, корневой элемент — stuff. Свои категории вкладываются прямо в него, имя элемента становится ключевым словом:

<stuff treeVersion="1.20.1">
  <myCategory>
    <dirt id="minecraft:dirt"/>
    <cake id="minecraft:cake"/>
  </myCategory>
</stuff>

Теперь myCategory соответствует только земле и торту. Убирать предмет из исходной категории не нужно; один предмет может быть в нескольких. Новые категории лучше ставить в начало, сразу под <stuff>.

ID и варианты

Некоторые предметы различаются только значением damage:

<sexyWools>
  <magentaWool id="minecraft:wool" damage="2"/>
  <pinkWool id="minecraft:wool" damage="6"/>
  <purpleWool id="minecraft:wool" damage="10"/>
</sexyWools>

Особые данные

Зелья и именованные предметы требуют дополнительных данных:

<specialPotion>
  <specialPotionA id="minecraft:potion" data='{Potion:"minecraft:strong_healing"}'/>
</specialPotion>

<specialPickaxe id="minecraft:diamond_pickaxe"
  data='{display:{Name:"My Special Pickaxe"}}'/>

Атрибуты

АтрибутГдеОписание
idПредметРегистрационное имя, например minecraft:stone
damageПредметЗначение варианта, по умолчанию подстановочное
dmin / dmaxКатегорияСоздать записи для диапазона damage
classКатегорияСопоставление по классу: armor, sword, bow, pickaxe, shovel, axe, hoe, shears, arrow, fishing
dataКатегорияУсловия вида data="toolclass:pickaxe", data="armortype:head"; через запятую
orderЛюбойПорядок среди соседних элементов
mergePrevious / mergeChildrenЛюбойПорядок объединения с предыдущим / дочерними
treeVersionКореньВерсия игры для дерева; только запись. При смене версии файл копируется в резерв и пересоздаётся

Расширение и объединение

Дополнительные фрагменты кладутся в config/InvTweaks/trees/ с расширением .tree и объединяются при запуске. Сломанный фрагмент можно удалить — он пересоздастся, старый сохранится как *.bak.

ВНИМАНИЕ Опечатка в ключевом слове дерева делает соответствующую строку правил недействительной; игра сообщает об этом в чате.

Совместимость контейнеров (InvTweaksCompatibility.xml)

По умолчанию файла нет; создайте его при необходимости. Он указывает, у каких контейнеров показывать кнопки:

<root>
  <!-- как сундук: кнопки сортировки -->
  <chest class="mod.container.MyChestContainer" row_size="9" large_chest="false"/>
  <!-- как обычный контейнер: только кнопка настроек -->
  <inventory class="mod.container.MyInventoryContainer" disable_buttons="false"/>
</root>

Он передаёт лишь базовую информацию и работает не со всеми модами; при проблемах с контейнером сначала обратитесь к автору мода за поддержкой API.

Вопросы и ответы

В чате «Mod can't work because it couldn't find…»

В jar не хватает ресурса конфигурации (обычно проблема сборки). Удалите config/InvTweaks/ и перезапустите — корректная сборка создаст его заново.

R не работает

Проверьте три вещи: клавишу сортировки (по умолчанию R, см. «Настройки → Управление»); экран допускает сортировку; курсор находится над ячейкой, что определяет область.

Модификатор + ЛКМ не работает

Проверьте enableShortcuts=true в InvTweaks.cfg и что «Горячие клавиши» включены в настройках. Клавиши не должны конфликтовать с ванильными.

R + цифра / удержание R не работает

При одном профиле переключаться не на что. Добавьте хотя бы один профиль, например Mining:.

Изменения конфигурации не применяются

Правила и клавиши применяются при следующей сортировке; после правки дерева перезапустите клиент. Если дерево было пересоздано, старый файл останется как *.bak.

Предметы из модов сортируются не так, как хочется

Отредактируйте InvTweaksTree.txt и добавьте предметы по id в нужную категорию. Чтобы узнать id, нажмите F3 + H для расширенных подсказок и наведите курсор на предмет.

Иконки выглядят плохо с моим ресурспаком

Кнопки рисуются ванильной текстурой. Добавьте в пак assets/inventorytweaks/textures/gui/button10px.png, чтобы заменить её.
