Inventory Tweaks Remaked

インベントリ整理、コンテナの並べ替え、自動補充、アイテムツリー — Minecraft 1.12.2 向け Inventory Tweaks の現代版ポートです。

お使いのゲームバージョンに対応する jar を mods フォルダへ入れるだけです。クライアント専用 MOD のため、サーバー側への導入は不要で、追加のパケットも送信しません。

ヒント 初回起動時に config/InvTweaks/ へ既定の設定が生成されます。チャットには何も表示されず、logs/latest.log に 1 行だけ記録されます。

クイックスタート

導入後にインベントリを開くと、タイトルバー右上に 「…」 ボタンが現れます。これが見えれば MOD は正常に読み込まれています。クリックすると設定画面が開きます。

  • R: カーソル位置のエリアを並べ替えます。インベントリを開いていなくても使えます。
  • マウス中ボタン: 並べ替え。チェストでは押すたびに 3 種類のアルゴリズムを切り替えます。
  • コンテナのタイトル行右側のボタン: 既定の並べ替え、縦、横、設定、アイテム移動。
  • Ctrl / Shift / Space / Alt + 左クリック: アイテムの移動・破棄。

ルール・プロファイル・アイテム分類は config/InvTweaks/ に保存されます。ゲームの再起動は不要で、保存してから並べ替えれば反映されます。

インストール

ローダーとゲームバージョンごとに jar が分かれています。インスタンスに完全一致するものだけを入れてください。

ローダーゲームバージョンjar ファイル名
Fabric1.20.1inventorytweaksremaked-fabric-1.20.1-1.0.0.jar
Fabric1.21 / 1.21.1 / 1.21.3 / 1.21.4 / 1.21.5 / 1.21.8 / 1.21.10 / 1.21.11inventorytweaksremaked-fabric-<version>-1.0.0.jar
Fabric26.1.2 / 26.2 / 26.3inventorytweaksremaked-fabric-<version>-1.0.0.jar
Forge 47.x1.20.1inventorytweaksremaked-forge-1.20.1-1.1.0.jar
NeoForge 21.x1.21 / 1.21.1 / 1.21.3 / 1.21.4 / 1.21.5 / 1.21.8 / 1.21.10 / 1.21.11inventorytweaksremaked-neoforge-<version>-1.1.1.jar
NeoForge 26.x26.1.2 / 26.2 / 26.3（Java 25 必須）inventorytweaksremaked-neoforge-<version>-1.1.0.jar

Fabric 版は対応する Fabric Loader と Fabric API が必要です。Forge / NeoForge 版に追加の前提はありません。

基本の並べ替え

R キーはカーソル位置に従う

並べ替える範囲はマウスカーソルの位置で決まります。インベントリを開く必要はありません:

カーソルの位置結果
チェスト（コンテナ）のスロットコンテナのみ並べ替え
インベントリ / ホットバーインベントリのみ並べ替え
クラフト枠、ボタン、GUI の空白コンテナとインベントリをまとめて並べ替え（コンテナが無ければインベントリのみ）

マウス中ボタン

中ボタンもカーソル位置で範囲を判断します。チェストでは押すたびに 既定 → 縦 → 横 を切り替えます。

例外として、カーソルがクラフト入力枠にあるときは並べ替えず、スタックを均等に分割します。棒を作るときに木材を上下へ均等に分ける、といった使い方ができます。

並べ替えアルゴリズム

アルゴリズム詰め方向いている場面
既定アイテムツリーの分類順に沿って詰める普段のインベントリやチェスト
縦（列ごと）1 列ずつ上から下へ列で分類したいとき
横（行ごと）1 行ずつ左から右へ行で分類したいとき

クリエイティブのインベントリ

クリエイティブのアイテム一覧には設定ボタンだけがタイトル行の右端に表示されます。R と中ボタンでクリエイティブの一覧が並べ替えられることはありません。

コンテナのボタン

以下のアイコンは MOD が実際に描画する 10×10 ピクセル絵を 30×30 に拡大したものです。約 0.8 秒カーソルを合わせると、表の「ツールチップ」が表示されます。

アイコン位置ツールチップ動作
並べ替え行の左端既定の並べ替え設定された既定アルゴリズムでコンテナを並べ替え
並べ替え行の中央列で並べ替え縦: 1 列ずつ詰める
並べ替え行の中央行で並べ替え横: 1 行ずつ詰める
並べ替え行の右端インベントリ設定Inventory Tweaks の設定画面を開く
インベントリ行の右端・左側アイテムをコンテナへ移動クリック: コンテナにある同種のスタックを補充。Shift: ホットバー以外すべて。Alt+Shift: すべて
インベントリ行の右端・右側アイテムをインベントリへ移動Shift: コンテナ内のアイテムをすべて回収
ヒント 縦・横ボタンはコンテナの幅が 9 スロット以下のときだけ表示されます。Sophisticated Backpacks など独自ボタンを描くコンテナでは、重ならないようボタン列が自動で左へずれます。

ショートカット

既定のキー割り当ては次のとおりです。インベントリの「…」メニュー、または config/InvTweaks/InvTweaks.cfg で変更できます。

操作既定キー説明
カーソル位置を並べ替えRインベントリを開かずゲーム中いつでも使える
並べ替え（アルゴリズム切替）マウス中ボタンチェストで既定 / 縦 / 横を循環
アイテムを 1 個移動Ctrl + 左クリックスタックから 1 個だけ移動
同種アイテムをすべて移動Ctrl + Shift + 左クリック同じアイテムのスタックをまとめて移動
スタックを 1 組移動Shift + 左クリックスタックごと移動
すべて移動Space + 左クリック種類を問わずエリア内の全アイテムを移動
上のエリアへ移動↑ + 左クリックコンテナ / インベントリの上半分へ
下のエリアへ移動↓ + 左クリック下半分へ
破棄Alt + 左クリックアイテムを地面に落とす
ホットバーの指定枠へ移動1–9 + 左クリック対応するホットバー枠へ直接入れる
プロファイル切替R + 1–9番号はルールファイル内の順序に対応
プロファイルを循環R を約 1 秒長押し順番に切り替え
注意 プロファイル切替はルールファイルに2 つ以上のプロファイルがある場合のみ動作します。既定では 1 つだけです。

自動補充

食事をした、ツールが壊れた、ブロックを使い切ったなどで手元のアイテムが減ると、インベントリから同種のアイテムを自動で現在の枠へ補充します。

設定項目既定説明
enableAutoRefilltrue自動補充のマスタースイッチ
autoRefillBeforeBreakfalseツールが完全に壊れる前に交換する
autoRefillDamageThreshhold5残り耐久がこの値を下回ったら交換

補充対象はルールファイルの autorefill 行で決まります。FROZEN の枠は自動補充の対象外です。

設定ファイル

すべて config/InvTweaks/ にあります:

ファイル役割
InvTweaks.cfgスイッチとキー割り当て（properties 形式）
InvTweaksRules.txt並べ替えルールとプロファイル
InvTweaksTree.txtアイテム分類ツリー（中身は XML）
trees/*.tree追加のツリー断片。起動時に本体へ統合
InvTweaksCompatibility.xml任意。他 MOD のコンテナ互換情報
ヒント ゲーム内の「…」→「並べ替えルールファイルを開く…」から直接開けます。保存してゲームへ戻り、もう一度並べ替えれば反映されます。

並べ替えルール（InvTweaksRules.txt）

1 行が 1 つの制約で、書式は 2 つの項目だけです:

<target> <keyword>

target はインベントリ内の位置（単一スロット、行、列、矩形）、keyword はアイテムツリーの分類名またはアイテム名です。たとえば D5 pickaxe と書くと、最下行（ホットバー）の 5 番目に最良のツルハシが入ります。

既定のファイルには D LOCKED が入っており、ホットバーへ自動でアイテムが詰め込まれないようになっています。

エリア指定

インベントリは 9 列 × 4 行で番号付けします。列は 1〜9（左から右）、行は a〜d（上から下、d がホットバー）です。

書式意味
D1単一スロット: D 行 1 列目
D行全体、左から右へ
1列全体、既定では下から上へ
A5-C9矩形: A5 から C9 まで
A1-C3矩形、角の順序違い（詰める向きが変わる）
ヒント 矩形は A1-C3、C3-A1、A3-C1、C1-A3 と書けますが、完全に同じではありません。始点の角によって詰め始める位置が変わります。

修飾子

target の末尾に付けます。組み合わせも可能です:

修飾子意味
r逆向き: 右から左、または上から下へ
v縦優先: 左右より先に上下へ（主に矩形）

たとえば Ar は 1 行目を逆向きに、A1-C5v は矩形を縦優先で埋めます。

キーワード

アイテム名と多くの分類名をそのまま使えます: pickaxe、edibleFood、blocks、equipment など。全リストはアイテムツリーファイルの中身です。

大文字小文字や空白は区別しません: woodenSword、WOODSWORD、Wooden Sword は同じ意味です。

ロックと凍結

書式効果
<target> LOCKED他のアイテムを入れない。より具体的な指定が優先される（D LOCKED は D1 torch に上書きされる）
<target> FROZEN枠内のアイテムは並べ替えでも自動補充でも一切動かない
autorefill <keyword>キーワードに一致するアイテムだけ自動補充（省略時はすべて）

複数プロファイル

単語 1 つとコロンだけの行でプロファイルを開始します。以降のルールはそのプロファイルに属します:

Mining:
D1 pickaxe
D2 torch

Fighting:
D1 sword
D5 edibleFood

R を約 1 秒長押しで循環、または 1〜9 + R で番号指定して切り替えます（最初が 1）。

公式の例

原作者が使っているルール:

Default:

D1 pickaxe
D2 axe
D3 shovel
D4 sword
D5 edibleFood
D9 torch

A1-C5v stuff
A9-C6v blocks

完全な例

# # から始まる行はコメント
[Default]
# 1 列目に武器
1 weapon
# 1 行目にブロック
a block
# 単一スロットに食料
a1 food
# 右下 2 枠をロック
b8-c9 locked
# ツールだけ自動補充
autorefill tool
注意 Default:（公式スタイル）と [Default]（セクション形式）のどちらも使えます。1 つのファイル内では統一してください。

アイテムツリー（InvTweaksTree.txt）

アイテムツリーは「ルールで使えるキーワード」と、同カテゴリ内でのアイテムの順序を定義します。順序は重要で、D1 sword では先に書かれた剣が優先されます。

構造と独自カテゴリ

中身は XML で、ルート要素は stuff 固定です。独自カテゴリはその中に直接入れ、要素名が新しいキーワードになります:

<stuff treeVersion="1.20.1">
  <myCategory>
    <dirt id="minecraft:dirt"/>
    <cake id="minecraft:cake"/>
  </myCategory>
</stuff>

これで myCategory は土とケーキだけに一致します。元のカテゴリから削除する必要はなく、1 つのアイテムを複数のカテゴリに入れられます。新しいカテゴリは <stuff> の直下、なるべく先頭に置くのがおすすめです。

ID とバリエーション

一部のアイテムは damage 値と組み合わせないと区別できません:

<sexyWools>
  <magentaWool id="minecraft:wool" damage="2"/>
  <pinkWool id="minecraft:wool" damage="6"/>
  <purpleWool id="minecraft:wool" damage="10"/>
</sexyWools>

特殊データ

ポーションや名前付きアイテムは追加データが必要です:

<specialPotion>
  <specialPotionA id="minecraft:potion" data='{Potion:"minecraft:strong_healing"}'/>
</specialPotion>

<specialPickaxe id="minecraft:diamond_pickaxe"
  data='{display:{Name:"My Special Pickaxe"}}'/>

属性

属性対象説明
idアイテム登録名。例: minecraft:stone
damageアイテムバリエーション値。既定はワイルドカード
dmin / dmaxカテゴリdamage の範囲でまとめて生成
classカテゴリクラス名で照合: armor、sword、bow、pickaxe、shovel、axe、hoe、shears、arrow、fishing
dataカテゴリdata="toolclass:pickaxe" などの条件。カンマ区切り
order任意同じ階層内での順序
mergePrevious / mergeChildren任意直前の項目 / 子項目との統合順序
treeVersionルートツリーの対象ゲームバージョン。記録用で、変化時はバックアップして再生成

拡張と統合

追加の断片は config/InvTweaks/trees/ に .tree 拡張子で置くと、起動時に本体ツリーへ統合されます。壊した場合は削除すれば再生成され、元ファイルは *.bak として残ります。

注意 ツリー内のキーワードを打ち間違えると、対応するルール行は無効なキーワードとしてスキップされ、ゲーム内チャットで通知されます。

コンテナ互換性（InvTweaksCompatibility.xml）

既定では存在しません。必要になったら作成します。どのコンテナにボタンを出すかを指定できます:

<root>
  <!-- チェスト扱い: 並べ替えボタンを表示 -->
  <chest class="mod.container.MyChestContainer" row_size="9" large_chest="false"/>
  <!-- 通常コンテナ扱い: 設定ボタンだけ -->
  <inventory class="mod.container.MyInventoryContainer" disable_buttons="false"/>
</root>

表現できるのは最小限の情報だけで、すべての MOD で動く保証はありません。挙動がおかしい場合はまず MOD 作者へ API 対応を相談してください。

よくある質問

チャットに「Mod は動作できません…見つかりません」と出る

jar から既定の設定リソースが欠けています（多くはパッケージの問題）。config/InvTweaks/ を削除して再起動すれば、正常なビルドなら再生成されます。

R を押しても反応しない

3 点を確認してください: 並べ替えキー（既定は R、「操作 → キー設定」で確認）、現在の画面が並べ替え可能か、カーソルがスロット上にあるか（範囲の判定）。

修飾キー + 左クリックが効かない

InvTweaks.cfg の enableShortcuts=true と、設定画面の「ショートカット」が有効か確認してください。バニラのキーと衝突していないことも必要です。

R + 数字 / R 長押しで切り替わらない

プロファイルが 1 つだけでは切り替え先がありません。Mining: などを 1 つ以上追加してください。

設定を変えても反映されない

ルールとキーは次回の並べ替えから反映されます。ツリーを編集した場合はクライアント再起動を推奨します。更新後にツリーが再生成された場合、config/InvTweaks/ に *.bak が残ります。

MOD アイテムが思い通りに並ばない

InvTweaksTree.txt を編集し、id を使って希望のカテゴリへ追加してください。id が分からないときは F3 + H で詳細ツールチップを有効にし、アイテムにカーソルを合わせると確認できます。

リソースパックでアイコンが変になる

既定ではバニラのボタン画像で描画します。リソースパックに assets/inventorytweaks/textures/gui/button10px.png を入れると差し替えられます。
