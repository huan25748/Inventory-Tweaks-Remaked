目录 快速开始 基础使用 快捷键 自动装填 配置文件 排序规则 物品树 常见问题

快速开始

把对应游戏版本的 jar 放进 mods 文件夹即可，纯客户端模组，服务器不需要安装。

游戏版本加载器jar 文件名
1.20.1Forge 47.xinventorytweaksremaked-forge-1.20.1-1.1.0.jar
1.21 / 1.21.1 / 1.21.3 / 1.21.4 / 1.21.5 / 1.21.8 / 1.21.10 / 1.21.11NeoForge 21.xinventorytweaksremaked-neoforge-<版本>-1.1.0.jar
26.1.2 / 26.2 / 26.3NeoForge 26.x（需要 Java 25）inventorytweaksremaked-neoforge-<版本>-1.1.0.jar

第一次启动会在 config/InvTweaks/ 下生成默认配置，聊天栏不会弹提示，只在 logs/latest.log 里留一行记录。

基础使用

R 键整理：跟着鼠标走

打开容器后按 R，整理哪个区域取决于鼠标指针停在哪：

鼠标指向结果
箱子（容器）里的格子只整理容器
背包 / 快捷栏只整理背包
合成格、按钮、GUI 空白处容器与背包一起整理（没有容器时就是整理背包）

鼠标中键

中键整理同样按鼠标位置判断区域。对箱子连续点击中键会在 默认 → 竖排 → 横排 三种算法之间循环。

容器上的按钮

下面的图标是按模组实际的像素绘制还原的缩略图（10×10 的按钮被放大到 30×30），游戏里看到的就是这个样子；鼠标停上去约 0.8 秒会弹出提示框，内容就是表里的「悬停提示」。

图标（按模组实际绘制还原）位置悬停提示作用
最左边默认排序方式用当前配置的默认算法整理容器
排序行中间按列整理竖排：一列一列地放物品
排序行中间按行整理横排：一行一行地放物品
最右边物品栏设置打开 Inventory Tweaks 设置界面
「物品栏」行右端，靠左转移物品至容器单击：只补容器里已有的同类物品；Shift：除快捷栏外全部；Alt+Shift：全部
「物品栏」行右端，靠右转移物品至物品栏Shift：把容器里的物品全部取回背包
竖排 / 横排按钮只在容器宽度 ≤ 9 格时出现；遇到「精妙背包 / 精妙存储」这类自带按钮的界面，整排按钮会自动左移避让，不重叠。

快捷键

默认键位如下，全部可以在 config/InvTweaks/InvTweaks.cfg 里改。

操作默认键配置项
整理鼠标所指区域R（可在「控制 → 按键」里改）—
整理（循环算法）鼠标中键enableMiddleClick
移动 1 个物品Ctrl + 左键shortcutKeyOneItem
移动所有同类型物品Ctrl + Shift + 左键shortcutKeyAllItems
移动所有物品空格 + 左键shortcutKeyEverything
移动到上方区域↑ + 左键shortcutKeyToUpperSection
移动到下方区域↓ + 左键shortcutKeyToLowerSection

键名写法：LCONTROL、RCONTROL、LSHIFT、LALT、SPACE、UP、DOWN、1~9，多个键写在同一行用 , 分隔，组合键用 + 连接，例如 LCONTROL+LSHIFT, RCONTROL+RSHIFT。

自动装填

手上的工具/物品用完或快坏时，自动从背包换一组新的到当前格。

配置项默认说明
enableAutoRefilltrue总开关
autoRefillBeforeBreakfalse保留式重装：工具坏掉之前就换
autoRefillDamageThreshhold5剩余耐久低于该值时触发交换

哪些物品允许自动补货由规则文件里的 autorefill 行决定（见下文）。

配置文件

全部位于 config/InvTweaks/：

文件作用
InvTweaks.cfg开关与按键（properties 格式）
InvTweaksRules.txt排序规则 / 多套方案
InvTweaksTree.txt物品分类树（内容是 XML）
trees/*.tree附加物品树片段，会和主树合并
删除这些文件后重新进游戏会自动重建；重建前会把旧文件备份成 *.bak。

排序规则（InvTweaksRules.txt）

每行一条规则，格式固定为两个字段：

<区域> <关键字>

关键字来自物品树里的类别名或条目名（如 weapon、food、dirt）。

区域写法

背包按 9 列 4 行编号：列 1~9（从左到右），行 a~d（从上到下）。

写法含义
1第 1 列（整列，默认从下往上填）
1r第 1 列，反向（从上往下）
a第 1 行（整行，从左往右）
ar第 1 行，反向（从右往左）
a1单个格子：第 a 行第 1 列
a1-c3矩形区域：从 a1 到 c3
a1-c3r矩形，反向填充
a1-c3v矩形，竖排优先（先上下、再左右）

特殊规则

写法含义
<区域> locked锁定该区域：整理时不会把其他物品移进去
<区域> frozen冻结该区域：里面的物品完全不动
autorefill <关键字>只对匹配关键字的物品自动补货（不写则全部）

多套方案

用 [方案名] 开头的行分段，游戏内可用 R + 数字 或按住 R 循环切换：

[Default]
1 weapon
a1-c2 food
9 locked

[Mining]
1 pickaxe
a dirt
autorefill pickaxe

完整示例

# 井号开头是注释
[Default]
# 第 1 列放武器
1 weapon
# 第 1 行放方块
a block
# 单格放食物
a1 food
# 右下角两格锁住
b8-c9 locked
# 只让工具类自动补货
autorefill tool

物品树（InvTweaksTree.txt）

物品树定义「规则里能用的关键字」以及物品在同类里的先后顺序。文件内容是 XML，根元素固定为 stuff：

<?xml version="1.0" encoding="utf-8" ?>
<stuff treeVersion="1.20.1">
  <equipment>
    <weapon>
      <iron_sword id="minecraft:iron_sword"/>
      <diamond_sword id="minecraft:diamond_sword"/>
    </weapon>
    <armor class="armor" data="armortype:head"/>
  </equipment>
  <blocks>
    <building id="minecraft:stone"/>
  </blocks>
</stuff>

结构说明

  • 类别：不带 id / class 的元素就是类别，可以任意嵌套，元素名就是关键字。
  • 条目：带 id 的元素是具体物品，元素名同样可以当关键字用。
  • 推荐每个物品条目名=英文物品名，类别名=英文类别，便于在规则里书写。

属性

属性用于说明
id物品注册名，如 minecraft:stone
damage物品变种值，默认通配
dmin / dmax类别按 damage 范围批量生成条目
class类别按类名匹配：armor、sword、bow、pickaxe、shovel、axe、hoe、shears、arrow、fishing
data类别附加条件，如 data="toolclass:pickaxe"、data="armortype:head"、data="isshield:true"；多个用逗号分隔
order任意同级内的先后顺序
mergePrevious / mergeChildren任意与上一项 / 子项合并顺序，用于让某些物品排在一起
treeVersion根元素树对应的游戏版本号，仅作记录

扩展与合并

把额外片段放进 config/InvTweaks/trees/，文件名以 .tree 结尾，启动时自动与主树合并；改坏了直接删掉会自动重建。

物品树里关键字拼错时，规则文件里对应的那一行会被当作无效关键字跳过，游戏内会在聊天栏提示无效关键字。

常见问题

聊天栏提示「Mod 无法工作，因为找不到…」

jar 里的默认配置资源缺失（通常是打包问题）。删掉 config/InvTweaks/ 重启，正常版本会自动重建。

按 R 没反应

确认：① 按的是排序键（默认 R，可在「控制 → 按键」里查）；② 当前界面是容器或背包；③ 鼠标停在格子上（决定整理哪个区域）。

修饰键 + 左键没反应

检查 InvTweaks.cfg 里 enableShortcuts=true，并确认「设置 → 快捷键」是开启状态；另外按键不能和游戏原有按键冲突。

R + 数字 / 按住 R 切换方案没反应

规则文件里只有一套 [Default] 方案时没有可切换的目标。至少再写一段 [Mining] 之类的方案才会生效。

改完配置不生效

配置在下次打开容器 / 重新整理时读取；也可以退出重进世界。规则与物品树改动后建议重启游戏客户端。
